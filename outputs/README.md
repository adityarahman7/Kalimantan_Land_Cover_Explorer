# Hasil terpilih

`figures/`, `tables/`, dan `reports/` disiapkan untuk artefak kecil yang layak ditampilkan pada portofolio. Belum ada hasil analisis.

Setiap artefak harus menyebut sumber data, versi, periode, satuan, metode atau skrip pembentuknya, dan keterbatasan. Jangan mencampurkan ilustrasi sintetis dengan hasil data asli tanpa label yang jelas. Berkas dalam folder ini tidak otomatis diabaikan Git; tinjau ukuran, isi, dan izin berbagi sebelum commit.
