# Checklist publikasi GitHub

## Sebelum push

- [ ] Tinjau `git status` dan diff seluruh berkas yang akan diunggah.
- [ ] Pastikan token, kredensial, informasi akun, dan data terbatas tidak tercantum, termasuk pada output notebook.
- [ ] Pastikan sampel, gambar, dan tabel yang dibagikan kecil serta diizinkan oleh lisensinya.
- [ ] Pertahankan label sintetis/belum terverifikasi pada prototipe dan dokumentasi terkait.
- [ ] Periksa README, tautan, dan status proyek.
- [ ] Pilih lisensi kode bila ingin memberikan izin penggunaan ulang secara eksplisit.
- [ ] Pilih nama, akun pemilik, dan visibilitas repositori.

Repositori remote belum dibuat atau dihubungkan oleh penyiapan struktur ini. Commit dan push dilakukan setelah peninjauan berkas. `.gitignore` membantu mengecualikan berkas, tetapi tidak menggantikan pemeriksaan isi dan tidak menghapus rahasia yang telanjur dilacak.

## Setelah implementasi tersedia

- [ ] Tambahkan langkah instalasi dengan versi dependensi yang telah diuji.
- [ ] Tambahkan pengujian dan otomatisasi yang sesuai dengan kode aktual.
- [ ] Tambahkan tangkapan layar asli dengan tanggal, sumber, dan status data.
- [ ] Perbarui hasil, batas interpretasi, serta petunjuk reproduksi.
